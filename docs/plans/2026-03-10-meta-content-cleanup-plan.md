# 商业计划书元描述内容清理计划

## 问题识别

当前商业计划书中存在大量不属于正式计划书的元描述内容,这些内容更像是"写作指南"而非正式商业文档。

## 需要清理的内容类型

### 1. 评委相关表述
- "评委快速判断"
- "评委核查"
- "帮助评委理解"
- "评委在有限时间内定位"
- "国赛评委"

**处理策略**: 改为面向投资人/合作方的正式表述,或直接删除

### 2. 比赛相关表述
- "比赛展示"
- "比赛样品"
- "比赛表达"
- "比赛平台"(作为获客渠道的除外)
- "从比赛作品走向"

**处理策略**: 
- 如果是描述获客渠道的"比赛平台",保留
- 其他改为"产品展示""市场验证"等正式表述

### 3. 章节末尾的infobox
每章结尾都有:
```latex
\begin{infobox}{本章可提炼为 PPT 的核心结论}
...
\end{infobox}
```

**处理策略**: 全部删除,这是写作辅助内容,不属于正式计划书

### 4. 占位图和待补提示
- `\placeholderfigure{...}{建议后续补充...}{...（占位）}`
- "建议后续补充"
- "待补"

**处理策略**: 
- 如果有实际图片,替换为正式图片
- 如果暂无图片,删除占位符,用文字描述替代

### 5. 附录中的写作指导内容
- "建议在后续迭代中补充"
- "便于后续统一调研口径"
- "为了避免后期出现"
- "正文章节到PPT的映射清单"整个section
- "证据核验与收集责任建议"整个section
- "下一轮迭代优先事项建议"整个section

**处理策略**: 
- 保留实际的证据索引和待补材料清单
- 删除所有写作指导性内容
- 删除PPT映射、迭代建议等section

### 6. 其他元描述
- "在正式提交版本中,可在不虚构经历的前提下补充"
- "该口径既方便...也便于..."
- "这样可以帮助评委..."

**处理策略**: 改为直接陈述,删除元描述

## 清理优先级

### 高优先级(必须清理)
1. 所有章节末尾的"本章可提炼为PPT的核心结论"infobox
2. 附录中的"PPT映射清单""迭代建议""收集责任建议"等section
3. 明显的"评委""比赛作品"等表述

### 中优先级(建议清理)
4. 占位图和"建议后续补充"提示
5. "后续""待补"等写作指导性表述
6. 附录中的模板建议section(可保留但需改写)

### 低优先级(可选清理)
7. 摘要中"比赛表达"等个别表述
8. 部分"建议"表述(如果语境合理可保留)

## 执行建议

1. **先处理高优先级**: 删除所有infobox和附录中的PPT/迭代相关section
2. **再处理中优先级**: 替换"评委""比赛作品"等表述
3. **最后处理占位图**: 根据实际情况决定是否补图或改为文字描述

## 预期效果

清理后的商业计划书将:
- 更像正式的商业文档,而非比赛作品
- 面向投资人/合作方,而非评委
- 去除所有写作指导性内容
- 保持专业性和可信度
