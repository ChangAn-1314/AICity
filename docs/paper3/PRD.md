- [ ] 在 `docs/paper3` 下建立完整的 LaTeX 商业计划书工程，主题为“智舆——AI城市舆情态势监测感知与决策推演系统”

## 总体写作约束

- [ ] 先设计 `paper3` 的目录结构、章节结构、图表结构与附录结构，再开始大段正文撰写
- [ ] 正文需覆盖摘要、背景痛点、技术研发、产品方案、市场分析、商业模式、落地成果、财务预测、团队治理、社会价值、风险控制、附录等完整章节
- [ ] 所有宏观结论必须尽量落到“智舆”项目自身，不要只堆砌泛行业数据
- [ ] 所有“2025 年国赛加分点”必须显式体现：AI+、真实性证据、核心壁垒、盈亏平衡、一手调研、竞品对比、产教融合、社会价值
