# paper3 商业计划书工程说明

`paper3` 是智舆项目商业计划书主工程目录，仅用于输出 2025 年比赛语境下的正式 LaTeX 商业计划书。

## 编译方式

- 推荐：`latexmk -xelatex main.tex`
- 兼容：连续执行两次 `xelatex main.tex`

## 目录结构

- `main.tex`：全文主入口
- `chapters/`：封面、摘要、正文、附录章节
- `picture/`：统一管理正文图片、截图、流程图素材
- `PRD.md`：详细撰写需求
- `PRD.micro.yaml`：细颗粒任务拆解
- `PRD.yaml`：阶段任务总表

## 写作约束

- 仅修改 `docs/paper3` 下内容，不回写 `docs/paper` 或 `docs/paper2`
- 所有未核实的订单、合同、金额、样本量均使用“待补充/待核实”口径
- 所有结论优先落到“智舆”项目自身，避免写成行业通用模板
- 正文需兼顾技术硬核、商业闭环、真实性证据、财务可解释性与社会价值

## 图片与图表规则

- 图片统一放在 `picture/` 下，命名建议使用 `chapterX-topic-yy.png`
- 图表标题统一采用“图 X-Y”“表 X-Y”格式
- 所有图表需在正文中解释其业务意义，不只做装饰

## 待补证据规则

- 已有材料：可直接在正文引用，并在附录建立索引
- 暂缺材料：在正文中标注“待补充”或“待核实”，不得伪造
- 建议优先补充：访谈纪要、问卷样本、系统截图、测试报告、合作意向材料
